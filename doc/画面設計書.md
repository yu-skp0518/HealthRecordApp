# 画面設計書

## 1. LoginController

| URL | HTTP | メソッド | View | 概要 |
|---|---|---|---|---|
| `/` | GET | `showLogin()` | `login.html` | ログイン画面を表示する |
| `/login` | POST | `login()` | - | ID・PASSWORDを認証し、ログイン状態を開始する |
| `/logout` | POST | `logout()` | - | ログイン状態を解除し、ログアウト処理を行う |

## 2. HealthRecordController

| URL | HTTP | メソッド | View | 概要 |
|---|---|---|---|---|
| `/index` | GET | `showInput()` | `index.html` | 健康情報の入力画面を表示する |
| `/submit` | POST | `submit()` | - | 入力内容を受け取り、登録・計算処理を行う |
| `/result` | GET | `showResult()` | `result.html` | 処理結果を表示する |
